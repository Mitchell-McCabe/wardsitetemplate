Ward Sync extension

Import reports from LCR or send reviewed attendance check-ins to LCR.

Download Ward Sync v2.0.3

Install in Chrome using Developer Mode
  1. Download the ZIP and extract it to a folder you can keep.
  2. In desktop Chrome, open the Extensions menu (the puzzle-piece icon) and choose Manage extensions.
  3. Turn on Developer mode. If an older Ward Sync extension is installed, disable it.
  4. Click Load unpacked and select the extracted folder containing manifest.json.
  5. Sign in to LCR, leave Leaders open, and launch Ward Sync V2 from Chrome’s Extensions menu.

In Ward Sync, choose the reports you want and click Import selected reports. To export attendance, choose a Sunday, preview the check-ins, and confirm the matches. Leave the date blank to skip export.
