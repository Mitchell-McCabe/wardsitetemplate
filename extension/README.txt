Ward Sync V2 · Developer mode

Extract the ZIP. Open Chrome's Extensions page, enable Developer mode, disable
the older Ward Sync extension, choose Load unpacked and select the folder
containing manifest.json. Click the Ward Sync V2 toolbar icon.

Open the intended ward in LCR. Unlock Leaders on ward.example.invalid.
Select the reports to import. Each report opens in a temporary tab and reports
its own result. Current callings use the saved Members roster. The Member List supplies the roster. Class and Quorum Attendance supplies
class assignments when available.

For attendance, choose a Sunday, preview the pending named check-ins, then
confirm the matches. The extension reopens LCR to verify presence before
marking check-ins synced in Leaders. Guest attendance stays in Leaders.
