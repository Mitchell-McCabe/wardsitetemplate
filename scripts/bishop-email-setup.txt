BISHOPRIC MEETING REQUEST EMAIL ALERTS

1. Sign into the site-owned Google account and open https://script.google.com/ .
2. Create a standalone New Project. Name it Bishopric Meeting Alerts.
3. In the Leaders Settings, open Bishopric meeting request alerts and save the
   executive secretary's email. Open Set up Google Apps Script and use
   Script to copy. Paste the full script into Code.gs, then save.
4. In Leaders, click Generate Apps Script key and copy it. Treat it as a
   password. In Apps Script, open Project Settings > Script Properties.
   Add these four properties:

   SUPABASE_URL
   Your ward project URL from config.js

   SUPABASE_PUBLISHABLE_KEY
   Your ward publishable key from config.js

   BISHOP_EMAIL_WORKER_KEY
   Paste the key generated in Leaders

   LEADERS_INBOX_URL
   The full URL of your ward’s Leaders page with #notes at the end

5. Go back to the Apps Script editor. Select installBishopEmailTrigger from the
   function dropdown and click Run. Approve the Google permissions when asked.
   In Triggers, verify that sendBishopRequestAlerts appears as a time-driven
   trigger. You do not need to deploy a public web app.
6. To test, temporarily set the recipient to a mailbox you control, submit
   a new request marked TEST, and wait for the next trigger (about five
   minutes). Confirm the link works, then switch to the secretary's address.
   Mark the test request handled in the Inbox.

When the calling changes, update the recipient in Leaders Settings. Do not
regenerate the script key unless you need to replace it. If you replace it, also
update the BISHOP_EMAIL_WORKER_KEY property in Apps Script. The script ignores
already handled requests and requests more than two days old. It sends only a
generic alert and the Inbox link; request details stay on the site.
